# Launch School Front End Work

This repository tracks my progress through the Launch School Front End portion of the Core Curriculum. Contains course-related exercises, projects, and practice work organized by subject and lesson. Each top-level folder represents a different area of study or course track.

## Folder overview

- `js210/` — JavaScript basics and language fundamentals exercises, practice problems, and debugging work.
- `js215/` — JavaScript practice focused on the JS215 course content and assessment preparation.
- `js225/` — JavaScript object-oriented programming and related lesson work.
- `ls202/` — HTML/CSS coursework, layout practice, design recreation, and front-end web page work.

## Purpose

This repo is a personal study archive for:

- keeping notes and code samples organized by topic
- reviewing work as I move through the front-end curriculum
